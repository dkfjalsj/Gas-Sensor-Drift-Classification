# 저장 위치 보완 기록
초기 .local_data/retraining/ 경로를 위한 .gitignore 추가는 과거 동결 해시 검사 6건과 충돌했음.
기존 .gitignore가 이미 data/ 전체를 제외하므로 data/retraining/을 사용하기로 결정함.
원래 .gitignore를 보관 사본 그대로 복원했고 과거 해시·검사 목적은 수정하지 않음.
실제 운영 데이터 등록 전 변경이며 저장된 사용자 데이터의 이동·삭제는 없음.
세션 분리 정책·검증 조건·기존 모델은 변경하지 않음. 초기 실패 로그는 별도 보관함.
고정 계획 중 로컬 저장 위치만 이 기록으로 보완함.
