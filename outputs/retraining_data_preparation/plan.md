# 20-A 데이터 준비 정책 v1
기존 service.read_upload 재사용. 재학습 gas 필수, 출처·실제 정답 확인 방식·행별 세션/시각 별도 관리.
원본 Batch 1~6만 기존 해시와 학습 분할 기록을 대조. 정확 중복 및 12자리 유효숫자 근접 중복을 보수적으로 차단. 원본9~10 열기 금지.
세션별 측정 구간이 엄격히 분리되어야 함. 최신 한 세션을 검증으로 고정하고 이전 세션만 학습으로 배정. 동일 시각/겹침/한 세션/클래스 누락은 보류.
동일 특징의 정답 충돌·세션 간 중복은 오류. 세션 내 중복·부분 결측·불균형·소표본은 경고 및 명시적 승인 필요.
두 분할 모두 6가스 필요. 클래스당 5개 미만 또는 최대/최소 support 10배 초과 시 경고. 결측은 대치하지 않고 비율 기록.
동일 등록은 content ID와 고정 분리 정책으로 재현. 저장은 .local_data/retraining/ 불변 디렉터리와 파일별 SHA 기록. 기존 검증 행/세션을 신규 학습으로 재사용하지 못하게 검사.
원본·모델·기존 보고서·해시 불변. 신규 학습/튜닝/평가/모델 교체/롤백 없음. Git 명령 실행 없음.
