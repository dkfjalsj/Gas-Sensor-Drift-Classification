6단계: 시간순 확장 학습 및 가스 분류 성능 개선

계산 결과와 테스트 요약

Validation에서는 기본 세 모델 모두 학습 범위 확장 후 개선됐다. Batch 9–10 동일 가중 Macro F1은 RF만 개선됐으며, LR은 소폭 하락, SVM은 거의 동일했다. pooled Macro F1은 세 모델 모두 개선됐다. 기본 세 모델의 평가 Acetaldehyde Recall은 하락했다.

Validation 우선 후보는 B_SVM_balanced. 평가 Batch [9]에서는 Toluene Recall이 여전히 0%다. 6종의 안정적 분류 문제가 모두 해결된 것은 아니다.

전체 테스트 49개 통과, 기존 사유 2개 실패. 신규 테스트 8개 통과. 상세: temporal_expansion_verification.md.

1. 실험 배경 및 목적

학습 범위를 Batch 1–3에서 1–6으로 확장했을 때 동일 미래 Batch에서 성능이 달라지는지 확인한다. 기존 설정의 통제 비교와 조건 B의 소규모 개선 실험을 구분한다. 실제 계산값은 표·그래프로, 해석은 본문으로 표시한다.

2. 기존 평가 자료 재지정과 한계

기존 자료를 재사용한 회고적·탐색적 평가다. 독립적인 최종 Test 성능이 아니다. 과거 평가 결과를 이미 관찰했으므로 현재 분할 내부의 정보 차단만으로 연구 전체의 선택 편향을 제거할 수 없다. 이전 1–5단계 결과와 모델은 보존한다.

9. 데이터 누수 및 보존 검사

Train/Validation/평가 간 행·정확 특징 중복 0건. 동일 특징의 근접 표본이나 측정 세션 의존성은 정확 중복 검사만으로 배제할 수 없다. 스케일러·결측값 처리는 각 Train만 Fit. 선정 시각·선정 파일 SHA와 평가 시작 시각을 evaluation_gate.json에 기록한다. 기존 파일 및 원본 해시 비교는 run_manifest.json에 기록한다. 전체 테스트 실행 결과는 outputs/temporal_expansion/tests.txt와 test_results.xml에서 확인한다. 과거 소스 해시 불일치와 과거 기록의 누락 임시 파일 관련 기존 실패는 임의 수정하지 않는다.

10. 해석의 한계 및 독립 검증 조건

차이는 센서 드리프트, 농도·측정 환경 변화, 학습 시기·표본 수·클래스 구성, 모델의 일반화 한계가 함께 관련될 수 있다. 원인을 드리프트 하나로 확정할 수 없다. Stage 5는 370개 Train과 다른 분할을 사용했으므로 그 점수와 현재 점수의 차이를 통제된 개선 효과로 제시하지 않는다. 새로운 측정 시기의 미관찰 자료와 농도·환경·세션 정보를 확보하고, 모델·전처리·선정 규칙을 고정한 뒤 독립 평가해야 한다.
