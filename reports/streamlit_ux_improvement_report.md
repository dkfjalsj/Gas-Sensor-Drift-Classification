# 19.5단계 Streamlit 사용자 중심 UI/UX 개선

최종 판정: **B — 주요 UI 개선 및 기능 회귀 검증 완료, 일반 브라우저 저장 완료 검증 미완료**.

## 개선 내용

기존 여섯 화면은 기술 용어와 표 중심이었음. 데이터 분석 → 분석 결과 → 상세 분석의 세 영역으로 재구성함.

- 데이터 분석: CSV 업로드, 즉시 입력 검증, 실제 행 수 안내, 분석 시작 버튼. 파일 형식과 gas 매핑은 접힌 도움말로 이동함.
- 분석 결과: 실제 측정값 수·예측 가스 종류 수·기준과 다른 구간 수 카드, 최다 예측 가스의 개수·비율, 한영 병기 가로 막대, 패턴 상태, 다음 행동 순서로 구성함. 최다 동률도 공동 최다로 표시함.
- 상세 분석: 행별 예측, 전체 가스 분포, MMD² 그래프·고정 임계값·창별 표, 선택적 정답 평가, 모델 지문, CSV 다운로드를 제공함. 기술 정보는 기본적으로 접힘.

업로드 위젯은 화면 이동 중에도 유지함. 분석 성공 후 결과로 자동 이동함. 파일 변경·제거 시 기존 결과를 비움. 잘못된 파일은 업로드 단계에서 오류를 표시하고 분석을 차단함.

## 용어와 해석

일반 화면에서는 ‘센서 측정 패턴 확인’, ‘기준과 다른 구간’, ‘다음에 할 일’을 사용함. MMD², 임계값, Accuracy, Macro F1, Confusion Matrix, SHA-256은 상세 화면에서 정확한 명칭과 함께 제공함.

경고는 기존 기준과 다른 패턴이라는 의미임. 가스 구성과 묶음 방식도 영향을 줄 수 있음을 안내함. 센서 고장·분류 정확도·농도·위험도·신뢰 확률을 추정하지 않음. 100행 미만과 결측값으로 인한 평가 불가를 구분함.

정답 평가 정책은 변경하지 않음. Macro F1은 업로드 정답에 존재하는 클래스만 대상으로 계산하며, 존재하지 않는 클래스의 Recall/F1은 기존 NA 정책을 유지함. 합성 입력의 화면상 숫자는 기능 점검 결과이며 연구 성능이 아님.

## 결과 동일성 및 보존

- `src/webapp/service.py`와 기존 감지 코드 수정 없음. 모델 학습·교체 없음.
- 99/100/101/200행 × 정답 유무의 8조건에서 CSV 3종의 SHA-256이 수정 전 기록과 정확히 일치함. CSV에는 예측·감지 점수·조건이 포함되므로 바이트 동등성으로 함께 확인함.
- 고정 임계값 `0.00825701197565701`, 창 크기 100행 유지함.
- 공식 분류 모델 SHA-256: `1d6b20c94d1580d799e05ab5a9ce746bdb272d74f70ec2ff964011fffecfde32`.
- 감지기 SHA-256: `de47661f66c69cdc7553f73acf1df9b721f65771d0301fe69a7a326f814fa4c5`.
- 사전 기록한 기존 코드·테스트·모델·보고서·산출물 1,436개 중 허용한 UI/테스트 변경을 제외한 파일에 해시 변경 없음. 모델 파일 수 325개 유지함.
- 변경 전 UI·테스트·실행 안내 사본을 `outputs/streamlit_ux/before/`에 보관함. 과거 해시 기록과 18·18.5·19단계 결과는 수정하지 않음.
- 원본 데이터 수정 없음. 원본 Batch 9~10 접근을 테스트 감사 훅으로 차단함. 해당 파일을 새로 읽어 해시를 다시 계산하지는 않았음.

## 테스트

- 대상 회귀 테스트: **44개 통과**. 기존 34개 + 신규 10개.
- 전체 `tests` 실행: **186개 통과, 기존 실패 2개, 제한에 따른 건너뜀 90개**. 신규 코드 실패 없음.
- 기존 실패: 과거 보존 목록의 임시 파일 `outputs/model_comparison/zNex~$haremetrics.csv` 부재, 과거 고정 모델 목록과 후속 단계에서 추가된 모델 목록 충돌. 이번 단계에서 생성한 모델은 없음.
- 건너뜀은 원본 Batch 9~10 접근 또는 과거 보호 파일 쓰기가 필요한 기존 검사임. 통과로 간주하지 않음. 제한 내의 전체 실행이며 무제한 전체 테스트 통과를 주장하지 않음.
- 기존 테스트의 화면 이동 목적지를 상세 분석으로 조정함. 잘못된 입력은 이제 즉시 차단되므로 버튼 비활성화와 오류 표시·이전 결과 제거를 검사함. 삭제한 테스트 없음.
- 과거 결과 파일에 다시 쓰던 보존 검사는 새 읽기 전용 `ux_audit.verify`로 연결함. 과거 기준값 갱신 없이 수정 전 신규 스냅샷과 비교함.
- 초기 실행에서 잘못된 입력의 비활성 버튼을 클릭하던 UI 테스트 1건이 실패하여 위와 같이 수정함. 수정 후 44개 모두 통과함. 사본 테스트의 중복 수집 문제는 사본 확장자를 `.snapshot`으로 바꾸어 해소함.

검증 로그: `outputs/streamlit_ux/full_tests.txt`, `full_tests.xml`, `targeted_tests.txt`, `targeted_tests.xml`. 전체 실행의 건너뜀 사유는 `full_test_skips.json`과 XML에 보관함. `test_access_blocks.json`은 마지막 대상 테스트 실행 기록임.

## 브라우저 및 다운로드

앱 내 브라우저에서 실제 합성 200행 정답 CSV 업로드, 입력 준비 안내, 분석 실행, 결과 자동 이동, 상세 화면, 다운로드 버튼 3종 클릭을 확인함. 1280×1100 데스크톱과 390×844 모바일에서 확인함. 모바일 제목이 상단 도구 모음에 가려지는 부분을 보정함. 모바일 메뉴 접기와 업로드 화면을 최종 확인함.

`desktop_result.png`는 최종 짧은 그래프 제목 및 모바일 여백 보정 직전의 결과 화면이며, `mobile_final.png`는 보정 후 시작 화면임. 캡처에 쓰인 입력은 기능 확인용 합성 데이터임.

서버 CSV 응답 3종은 HTTP 200이며 Content-Disposition의 파일명과 바이트 내용이 기대 결과와 정확히 일치함:

| 파일 | 행 수 | 응답 바이트 |
|---|---:|---:|
| gas_classification.csv | 200 | 529,044 |
| distribution_windows.csv | 2 | 603 |
| analysis_summary.csv | 1 | 723 |

실제 응답 사본과 SHA-256은 `browser_downloads/`, `download_http_verification.json`에 보관함. 연결 가능한 일반 Chrome/Edge 브라우저가 없어 일반 브라우저의 다운로드 폴더 저장 완료는 확인하지 못함. Downloads에 있던 같은 이름의 과거 파일은 이번 확인의 증거로 사용하지 않음. 서버 응답 검증을 브라우저 저장 완료 검증으로 대체하여 주장하지 않음. 이 제한 때문에 A가 아닌 B로 판정함.

## 파일 및 실행

수정: `src/webapp/ui.py`, `tests/test_streamlit_integration.py`, `README_streamlit.md`.

신규: `src/webapp/ux_audit.py`, `src/webapp/ux_testing_guard.py`, `tests/test_streamlit_ux.py`, 본 보고서, `outputs/streamlit_ux/` 내 고정 계획·보존 기록·동등성 기준·테스트 로그·HTTP 응답·화면 캡처.

프로젝트 루트 PowerShell 실행:

```powershell
.\.venv\Scripts\python.exe -B -m streamlit run app_streamlit.py --server.address 127.0.0.1 --server.port 8501 --server.headless true --browser.gatherUsageStats false
```

현재 로컬 앱: <http://127.0.0.1:8501>. 최종 서버 정보는 `outputs/streamlit_ux/server_process_final.json`에 있음.

제한을 유지하는 테스트 재실행:

```powershell
.\.venv\Scripts\python.exe -B -m pytest tests -q -p src.webapp.ux_testing_guard -p no:cacheprovider
```

## 남은 점과 다음 단계

일반 브라우저에서 CSV 3종의 실제 저장 완료를 확인해야 함. 이번 검증은 지정한 화면 크기의 가독성과 기능 흐름 점검이며 다양한 실제 사용자의 이해도 연구나 모든 기기·브라우저 검증은 아님.

추론용 UI를 다음 개발 단계의 기반으로 사용할 수 있음. 반자동 재학습 운영 준비가 완료됐다는 의미는 아님. 향후 재학습 단계는 라벨 확보·검증 분리·모델 승인/되돌리기·보존 정책을 별도 설계해야 함. 이번 단계에서는 구현하거나 실행하지 않음. Commit·Push 수행 없음.
