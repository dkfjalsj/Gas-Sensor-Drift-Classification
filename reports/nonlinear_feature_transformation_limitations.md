# 14단계 연구 한계

새 독립 Test 없음. 과거 Fold는 반복 사용된 개발 자료이며 서로 독립적인 반복 표본이 아님. Batch 9~10 신규 평가 없음. 공식 Model A 유지.

- 6종 가스의 균형 개선은 모든 사전 보호 조건 통과로만 판정함.
- Fold A Toluene 학습 79개, Fold C Validation Toluene 18개. 작은 support의 불확실성 존재.
- 겹치는 학습 구간과 반복 사용한 Validation으로 선택 편향 존재. 독립 미래 CI·통계적 유의성 미주장.
- C와 gamma 정책은 고정하되 실제 gamma 및 거리 구조는 각각 기록.
- Train 수치 오류의 특징별 항등 처리와 상수 특징은 통계 CSV에 공개. 평가 오류는 조건 실패로 기록.
- 농도·환경·세션 정보 부족으로 드리프트 단독 원인 확정 불가.
- 학습 시간은 재사용 기준의 이번 학습 0초와 과거 시간을 구분. 실행 환경에 따른 시간 변동 존재.
- 기존 테스트 5개 실패는 변경하지 않음. 과거 보존 기록과 전역 모델 목록 충돌을 신규 결함과 구분.
- 추가 튜닝·앙상블·미래 Batch 신규 평가·공식 모델 교체 없음.
